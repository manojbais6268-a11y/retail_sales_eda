
# Retail Sales Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on retail sales data to identify sales trends, customer behavior, product performance, and discount impact on profitability.

## Objectives
- Analyze monthly and quarterly sales trends.
- Understand customer demographics.
- Identify top-selling products and categories.
- Study the relationship between discounts and profit.
- Generate actionable business insights.

## Dataset
The dataset contains 6,000 retail order-line transactions from January 2023 to December 2025.

File: `retail_sales_data.csv`

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights
- Sales show seasonal peaks during Q4.
- Customers aged 26–45 form the largest age segment.
- Electronics contributes the highest revenue.
- Higher discounts are associated with lower profit margins.

## Project Structure
- `retail_sales_eda.ipynb` — EDA notebook
- `retail_sales_data.csv` — Dataset
- `README.md` — Project documentation
- `requirements.txt` — Python dependencies

## How to Run
1. Clone or download this repository.
2. Install the required libraries.
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Run the notebook cells.
